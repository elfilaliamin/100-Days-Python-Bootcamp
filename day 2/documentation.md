# Tip Calculator

**Description:**
A simple Python command-line application that calculates how much each person should pay when splitting a bill and adding a tip.

**What I learned:**

* How to convert user input from strings to numbers using `float()`
* How to perform calculations with multiple values
* How to use variables to store user input
* How to use f-strings to display calculated results

**Notes:**

* `input()` returns a string, so convert it to `float()` before doing calculations
* Check the calculation order when combining the bill, tip, and number of people
* Spelling mistakes in variable names, such as `resutlt`, can make code harder to understand
