# Band Name Generator

**Description:**
A simple Python command-line application that generates a band name by combining the user's hometown and pet's name.

**What I learned:**

* How to get user input with `input()` and display output with `print()`
* How to store data in variables
* How to combine strings using concatenation
* How to use comments (`#`) to explain code

**Notes:**

* Add spaces or formatting when combining multiple strings
* `input()` always returns the user's input as a string
* `\n` can be used inside prompts to create a new line
